# 老黄历 · 择吉日

本地网页版 + 安卓 App：**传统历法工具**（文化工具类目，非算命）。程序精确计算**干支纪年月日、24 节气时刻、十二建除、黄道黑道、冲煞、彭祖百忌、宜忌、吉时**，支持按事项（结婚嫁娶 / 搬家入宅 / 开业开市 / 剖腹产预约等 26 项）筛选未来 90 天的吉日，可选 AI（GLM 流式）用白话讲解当日的历法逻辑。

**零第三方依赖**：Python 标准库 + 原生 JS，所有历法数据均由天文算法与规则推导**程序计算**，不查表硬编码年份。

## 功能

- **今日黄历卡**：公历日期 + 干支纪年（以立春为界）/月（五虎遁）/日（JDN 锚点法）+ 生肖年 + 节气标注（当日交节或下一节气倒计时）+ 宜/忌两栏对仗 + 冲煞 + 吉神/凶神 + 十二建除 + 黄道黑道 + 彭祖百忌 + 吉时。
- **择吉日**：选事项（26 项）+ 可选填自己生肖 → 未来 90 天内筛选「宜该事项且不冲生肖」的吉日，逐日给出推荐吉时；剖腹产预约等事项额外要求黄道吉日（现代引申事项，已注明）。
- **月历视图**：整月格子，红=黄道吉日、暗=破日/岁破/四离四绝、平=其余；格内小字为当日建除值神，节气日标注节气名；点任意一天看完整黄历。
- **节气页**：全年 24 节气精确时刻表（太阳视黄经天文算法）+ 下一节气倒计时；「节」定月建、「气」为中气。
- **AI 讲历法**（可选）：「让 AI 讲讲今天为什么忌动土」——GLM 流式输出，白话解释当日宜忌的历法依据与民俗逻辑；AI 只做翻译，数据全部由程序计算，提示词禁止 AI 改动排盘。

## 历法算法与出处

| 内容 | 算法 | 出处/依据 |
|---|---|---|
| 干支纪日 | JDN 锚点法，锚点 **2026-11-05 = 癸未日**（六十甲子序 19） | 便民查询网等多源万年历核对 |
| 节气时刻 | 太阳视黄经天文算法（Meeus 低精度，含光行差+章动修正，误差约分钟级） | *Astronomical Algorithms*（Meeus）；2026 立春 02-04 04:02 / 立冬 11-07 17:51 校验 |
| 月建 | 以「节」为界，交节时刻所在公历日即换月建（立春=寅月……小寒=丑月） | 《钦定协纪辨方书》 |
| 干支纪年/生肖 | 以立春为界 | 八字历法正例 |
| 月干支 | 五虎遁（甲己年丙寅首……），子/丑月步数先对 12 取模 | 五虎遁月起例诀 |
| 十二建除 | 值神 = 建除[(日支 − 月建) mod 12]。交节当日因月建前移一位，公式自动与前一日同值——即《协纪辨方书》「交节重复前值」的排法（(b_H−(m+1)) ≡ (b_{H−1}−m) mod 12 恒等）。故每一位每月必出现，**不缺「除」位，无需人工补位**（性质测试全覆盖） | 《钦定协纪辨方书·建除十二神》 |
| 黄道黑道 | 青龙起始支序 = (月建×2+8) mod 12，口诀「子午临申地，丑未戌上寻，寅申居子位，卯酉却加寅，辰戌龙位立，巳亥午中行」；青龙/明堂/金匮/天德/玉堂/司命为黄道，余黑道；时辰黄黑道同法以日支代月建 | 《神枢经》/《协纪辨方书》黄黑道起例 |
| 冲煞 | 日支六冲（支序+6）定生肖；煞方按日支三合组（申子辰煞南、巳酉丑煞东、寅午戌煞北、亥卯未煞西）；「冲×(干支)」取天克地冲（戊己无天干冲，借丙壬/丁癸之对） | 通行黄历冲煞定例 |
| 彭祖百忌 | 民间通行本《彭祖百忌歌》全文；可对应现代事项的（如己不破券→忌签约、亥不嫁娶→忌嫁娶）转为忌事项，已注明引申 | 民间通行本 |
| 宜忌生成 | 建除宜忌为基底 + 黄道神追加吉事/黑道神追加忌事 + 月建六合（六合吉神）+ 彭祖忌映射 + 月破/岁破诸事不宜 + 四离四绝大忌；忌优先去重，**宁缺勿滥** | 综合通行通书归纳，逐条注明于 `static/rules.json` 的 `_meta` |

**全部文化规则数据集中在 [`static/rules.json`](static/rules.json)**（建除宜忌表、黄黑道注记、彭祖歌诀、事项目录），并附出处与推导逻辑说明；引擎只做算法。

## 配置 AI 服务（设置页）

**GLM 智谱**（OpenAI 兼容）：Base URL `https://open.bigmodel.cn/api/paas/v4`（Coding Plan 为 `/api/coding/paas/v4`），模型 `glm-5.3`，建议开启「快速模式」（关闭深度思考）。API Key 只保存在本机（服务模式在 `data/config.json`，App 在本机 localStorage），请求直连对应服务。

## 安卓 App

同一套前端（`static/`）通过 [Capacitor](https://capacitorjs.com) 打包：App 内置 JS 历法引擎（离线计算全部黄历/择吉）、直连 AI、含自研原生 SSE 插件（流式输出，绕过 WebView CORS）。

```bash
cd mobile && ./build.sh
# 产物：老黄历择吉日.apk（正式签名版）、老黄历择吉日-debug.apk
```

- build.sh 自动在 `./tools`、`../tools`、`../liuyao/tools` 三处寻找 JDK21 + Android SDK（与六爻项目共用工具链）。
- 权限仅 INTERNET；适配挖孔（`adjustMarginsForEdgeToEdge` + 状态栏底色与宣纸底一致）。
- 正式签名密钥 `mobile/almanac-release.jks` + `mobile/keystore.properties`（均不入库，**务必备份**，丢失后无法对已装用户发布升级）。

## 项目结构

```
almanac/
├── app.py            # 本地服务：静态页 + 黄历 API + LLM 流式代理（Python 标准库）
├── almanac.py        # 历法引擎：干支/节气/建除/黄黑道/冲煞/彭祖/宜忌/吉时/择吉（纯计算）
├── static/
│   ├── rules.json    # ★ 文化规则数据表（唯一数据源，注明出处与推导逻辑）
│   ├── engine.js     # almanac.py 的 JS 移植（250 组向量逐字段一致）
│   └── app.js / index.html / style.css   # 前端（原生 JS，无框架）
├── mobile/           # Capacitor 安卓工程（www 为 static 的同步副本）
├── tests/
│   ├── test_almanac.py     # 引擎向量与性质测试（36 项）
│   ├── test_api.py         # stub LLM 全链路 + API 一致性（11 项）
│   ├── gen_vectors.py      # 生成 Python↔JS 一致性向量（vectors.json）
│   ├── test_engine.js      # JS 引擎 250 组向量逐字段比对
│   └── test_app_client.js  # 离线模式 + 模拟 Capacitor 原生环境回归
└── data/             # config.json（AI 配置，不入库）
```
